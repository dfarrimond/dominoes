# Little Dominoes

A simple, mobile-friendly dominoes game designed for young children to play with a parent or caregiver.

## Features

- Large touch-friendly dominoes
- Simple double-six domino rules
- Highlights playable pieces
- Gentle move hints
- Simple computer opponent
- Works offline
- No dependencies or build step

## Run locally

Just open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Push the contents of this folder to the repository.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save.

GitHub will then publish the game as a website.
